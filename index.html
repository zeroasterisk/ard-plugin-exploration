User Experience Pillars

• Pre-Execution Auth Awareness: The agent inspects status: needs_onboarding upfront, preventing blind execution crashes and confusing 401/403 errors.

• Strict Opt-Out Control: Users who say "never ask again" have their preference stored in preferences.json or memory, permanently filtering out managed cloud tools.

• Graceful Offline Fallbacks: Cloud tools link to offline skills (e.g. BigQuery MCP ➜ BigQuery SQL Guidelines Skill).
